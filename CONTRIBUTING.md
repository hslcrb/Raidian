# Contributing

Thank you for improving Raidian. Please file a focused issue before broad UX changes. Use a `chatgpt-extrahigh/feature/detail` namespace for agent-authored work, or a descriptive feature branch for community contributors. Make small, testable commits; the preferred format is an English Conventional Commit prefix followed by a Korean message, for example `fix: 한글 경로 처리 개선`.

Run `python -m unittest discover -s tests -v` before opening a PR. Favor Python standard library, clear labels, keyboard support and practical error messages. Do not include copyrighted fonts without explicit embedding and distribution permission.
