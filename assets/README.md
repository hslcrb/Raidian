# Optional bundled fonts

Place an appropriately licensed `.ttf` font in `assets/fonts/` to bundle it in the portable EXE.
Raidian attempts to register these fonts privately on Windows, then selects Wanted Sans,
Pretendard, or a Korean-capable installed system font. Fonts are NOT downloaded automatically.
The user-referenced attachment was not available in this session; no font is falsely represented
as embedded. Verify distribution and embedding rights before placing a font here.
