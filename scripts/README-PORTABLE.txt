Raidian · 레이디안 0.1.0
작은 Git 작업실. Tiny Git, clear history, happy commits.

1. Raidian.exe 를 더블클릭하면 GUI가 열립니다.
2. Raidian-CLI.exe --json doctor : 실행환경 확인
3. Raidian-CLI.exe --repo "C:\work\repo" --json status : JSON 상태 조회
4. Raidian-CLI.exe mcp --repo "C:\work\repo" : 읽기 전용 MCP 서버

Python 설치는 필요 없습니다.
하지만 Git for Windows는 반드시 설치되어 있어야 합니다.
GitHub PR 연동은 gh CLI를 별도 설치 및 로그인해야 작동합니다.
이 파일을 받은 출처와 SHA256SUMS.txt 체크섬을 검증하세요.
